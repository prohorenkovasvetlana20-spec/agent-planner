# agent-planner
AI-ассистент для планирования дня (Женя).

## Что внутри
- `prompts/agent-prompt.txt` — системный промпт агента.
- `examples/plan-example.csv` — пример CSV-вывода.

## Как использовать
1. Взять промпт из `prompts/`.
2. Вставить в интерфейс AI-ассистента.
3. Передавать задачи и получать план в CSV.
